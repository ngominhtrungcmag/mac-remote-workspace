## 4. Release tooling note

`scripts/release-macos.sh` signs nested code, `RdpSessionHelper`, the main executable and the bundle with Hardened Runtime and `scripts/MacRemoteWorkspace.entitlements` (empty), then runs `notarytool submit --wait`, `stapler`, and `spctl`. It is dry-run unless `DEVELOPER_ID` is set, and skips notarization unless `NOTARY_PROFILE` is set. It was only exercised in dry-run mode (`bash -n` plus a fake bundle); nothing was signed or submitted. `bundle-app.sh` still applies an ad-hoc `codesign --deep`, which the release script overrides with `--force`. Open item for the RDP owner: confirm all FreeRDP code is statically linked or placed under `Contents/Frameworks` so it is signed inside-out; if a nested dylib is not signed with the same Team ID, hardened runtime will need `disable-library-validation`.
